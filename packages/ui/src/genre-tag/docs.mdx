# GenreTag

Display-only drink categories. One React Native implementation serves iOS,
Android, and web; no native Host is needed.

```tsx
import { GenreTag, GenreTagList } from "@is-this-tasty/ui";

<GenreTag genre="DIPA" />;
<GenreTagList genres={["DIPA", "Rosé", "Bourbon"]} />;
```

## Current genres

Hues come from every key in the shared `category` map, not UI chrome colors.

<Preview><CurrentGenresExample /></Preview>

## Unknown genre

Unknown names retain their label and use `categoryFallback`. Fallback text uses
`label2`, not `label3`, to meet 4.5:1 contrast on the `separator` chip fill.
Lookup is exact and case-sensitive; inherited object keys are unknown names too.

<Preview><UnknownGenreExample /></Preview>

## Overflow

Lists show the first three tags, then a non-interactive `+N` chip. Its accessible
label includes the omitted genre names. Input order and duplicates are preserved.
An empty list renders nothing.

<Preview><OverflowExample /></Preview>

## Wrapping

Lists wrap with an 8pt gap. Labels can wrap and respect system font scaling;
there is no fixed chip height or truncation.

<Preview><WrappingExample /></Preview>

## Typography and accessibility

The label intentionally overrides `Text variant="meta"` locally with 10pt bold
uppercase and 0.4pt tracking (4%). This component-specific exception does not add
an eighth typography variant. Neutral chips use a 4pt continuous radius, 3pt
vertical / 7pt horizontal padding, and a decorative 5pt dot.

The text carries the category meaning, so color is never the only cue. Decorative
dots are hidden from accessibility. No button role, press handler, or tab stop is
added. `pnpm check` verifies category and fallback text contrast on the chip fill.

## Do / don't

- **Do** use `GenreTagList` for bounded drink-row metadata.
- **Do** add product-approved hues to the shared token map and regenerate CSS.
- **Don't** make tags tappable; use Picker or ContextMenu for filtering.
- **Don't** use genre colors to decorate navigation or other UI chrome.

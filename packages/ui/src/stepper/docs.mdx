---
title: Stepper
description: Native count controls with a web number field.
---

Use `Stepper` for small bounded counts such as the number of pours. The value
is controlled by the caller; `min` defaults to `0` and `step` defaults to `1`.

<Preview example="stepper/count" />

| | iOS | Android | Web |
| --- | --- | --- | --- |
| Control | SwiftUI `Stepper` | Compose `Row` and `IconButton`s | Base UI `NumberField` |

Custom React Native row: label thumb, name, producer and a compact rating.
One implementation serves iOS, Android and web; no native Host is needed.

```tsx
<DrinkRow drink={drink} badge="dex" menu={pourMenu} onPress={openDrink} />
```

The row reads as one accessible element: "Pliny the Elder, Russian River Brewing, rated 4.6, in your Dex".
With a custom `trailing`, the rating is dropped from the label; describe the trailing content yourself.

## Do / don't

- Do pass `menu` for the pour menu (see ActionMenu). It opens on long-press on iOS and Android, and on right-click (or long-press on touch) on web. Tap still calls `onPress`.
- Do let names truncate; both lines stay on one line.
- Don't put chromatic color in `trailing`; gold is reserved for rating.

## Enhancements

- **Virtualization.** The 200-row example uses `FlatList`. If it drops frames on a mid-range Android device, swap in LegendList (a `FlatList`-style API that also runs on react-native-web, so web needs no separate virtualizer). On iOS, `@expo/ui`'s native `List` recycles rows already.
- **Native swipe and reorder.** Swipe actions use RNGH today. Move to native `List` with `SwipeActions` and `onMove` once it can be checked on a device.

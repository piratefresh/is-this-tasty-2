Native button: SwiftUI on iOS, Compose on Android, Base UI on web. 46pt tall,
pill shape, 17pt semibold label. The OS draws the pressed state.

```tsx

<Button variant="tinted" label="Log a pour" onPress={log} />;
```

`loading` disables the button and appends an ellipsis. `systemImage` (SF Symbol)
is iOS only.

## Primary

Neutral pill. The main action on a screen: use at most one.

## Destructive

System destructive role, announced by VoiceOver/TalkBack, e.g. "Leave club".
Don't use it for reversible actions.
